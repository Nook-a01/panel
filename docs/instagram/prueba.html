Prueba de tamaño

Dos favoritos que sólo muestran un cartel. El grande pesa lo mismo que el panel; el mediano, un tercio.

Con cada una (primero la grande):

  1. Tocá el botón para copiarla.
  2. Creá un favorito: ⋮ → estrellita ☆ → Editar. De nombre poné Grande (o Mediana). En URL borrá todo y pegá.
  3. Entrá a instagram.com, tocá la barra de arriba, escribí el nombre y tocá el de la estrellita.
  4. Fijate si aparece el cartel "funciona GRANDE" o "funciona MEDIANA".
